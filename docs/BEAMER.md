# Beamer 幻灯片模式

预览右上角的 SVG 展开图标暂时隐藏源码，只保留左侧列表和大预览；再次点击或按 Esc 返回编辑。展开期间可浏览不同子文件的幻灯片，窗口保持在预览中；返回编辑时定位到选中的幻灯片。没有切换幻灯片时保留原光标、选区和滚动位置。半屏可通过模式菜单“展开预览”进入；源码查找、编辑正文和进入专注模式会先恢复编辑布局。

`Ctrl+F` 查找栏位于源码区域内部，右边缘与编辑区对齐，不占用幻灯片预览顶部。窄编辑区内查找控件自然换行，范围选择保持可见。

打开 Beamer 或 ctexbeamer 时自动进入幻灯片模式；也可在“格式”菜单或命令菜单中切换，快捷键为 `Ctrl+Alt+B`。模式菜单可以关闭自动识别，手动选择优先。新建菜单提供简洁幻灯片模板。普通论文只做一次文档类型识别，不启动持续的幻灯片解析或预览任务。

## 写作与导航

目录顶部直接提供“导言”和“全文”。全文显示当前文件所有源码；点击幻灯片只定位代码，跨源文件继续保留全文编辑方式。按钮随之显示“返回单页”，可恢复当前张编辑。编辑文末直接在全文使用 Ctrl+End，无额外常驻入口。

- 左侧按逻辑 frame 列出标题，可按标题、编号、章节和正文／备用页筛选；单页不重复显示“1 步”。单击定位源码及已核验的 PDF 页面，左右方向键切换逐步显示或内容续页，双击修改标题。无标题首张不推测为封面；实际包含标题页命令时标为封面，`againframe` 显示为“再次显示：原页标题”。提示区说明逐步显示、内容续页、重复引用及备用页的区别。
- 直接点击“文档设置”编辑标题、副标题、作者、单位、日期、主题、配色、字体主题和页面比例；旁边箭头保留导言、主题与模板、公共宏和完整源码入口。标准声明保留可选短标题、已有选项和自定义宏，整次修改可一步撤销；重复、条件化或位于子文件的声明由源码入口处理，不自动生成覆盖声明。
- “总览”继承搜索与筛选，按需渲染缩略图，最多缓存 24 张。窗口可保持打开；单击选择，双击或 Enter 编辑。支持多选复制、删除、移动和拖动排序，沿用源码边界保护与一步撤销；目录更新后自动刷新。
- “备注”在当前预览下方展开，可同时看正文和备注；多段备注分别保留。切页、收起、保存、另存为及导出时应用草稿；花括号不配对或源码变化时保留草稿并说明原因，可明确放弃改动。备注不是自动写入磁盘，仍遵循文档保存流程。
- “导出”可选原有设置、投影版、讲者版或同时导出两版，并选择目录与文件名前缀。导出使用当前未保存内容的临时副本，分别生成 `-projection.pdf`、`-speaker.pdf`；不修改导言或替换编辑器预览。覆盖已有文件须确认；编译失败或取消不发布未完成的版本。保存期间若目标文件变化则停止覆盖。导出前所有版本都须编译成功；多个文件发布不是跨文件事务，若保存中断会列出已经成功保存的文件。
- “新建”菜单或幻灯片右键菜单中的“插入图片…”将 PNG/JPEG/PDF 复制到项目 figures 目录，生成稳定的相对引用；支持含中文或空格的原始路径。插入源码可一步撤销，图片文件保留以免影响其他引用。
- 点击子文件中的幻灯片时，目标源文件窗口继承主讲稿、整份目录、当前张与筛选；可直接从该目录前往下一张，不必先返回主文件。各文件仍使用自己的保存、恢复和撤销栈。主文件上下文只在当前会话内保持，不写入源文件或个人设置；退出该窗口的幻灯片模式时释放。当前实现仍沿用独立源文件窗口，未合并为多标签编辑器。
- 目录顶行合并新建、总览与收起；导言/全文直接入口保留，搜索旁的筛选菜单代替单独下拉框行，激活筛选时强调筛选按钮。预览只保留一条页码、步骤、备注、导出操作行。文档设置位于底部；标题与编号分列，长标题随目录宽度换行，最多三行，完整内容保留在提示中。切换源文件时延续目录阅读位置、窗口尺寸和面板显隐；目录标题始终标明所属主讲稿。
- 文档设置分为“基本信息”“外观”“导言与模板”。主题、配色、字体可从常用项选择，也可输入自定义名称；底栏只放取消／应用。“导言与模板”直接列出对应源码文件；已有改动时显示“应用并编辑源码”，应用后可一步撤销，校验失败留在错误字段。取消不改动原文。
- 编辑区只显示当前 frame 的源码；底层仍是完整的原始 `.tex` 文档。导言、主题与模板、公共宏有独立源码入口，“完整源码”可恢复全文视图。退出模式恢复所有源码。
- 当前张预览和目录可以分别收起。窄于 960 逻辑像素时自动收起预览，窄于 620 时也收起目录；恢复宽度后还原自动收起的面板，手动选择优先。专注模式只编辑完整代码：暂停 Beamer 自动识别、逐页解析与专用快捷键，隐藏目录和预览；退出后恢复原来的编辑方式与面板显隐。编译及普通代码操作继续可用。
- 当前张的选中全部、首尾导航及边界退格限制在显示范围内。跨范围的程序选区会显示完整源码；原有保存、恢复、编译和撤销仍作用于完整文档。

## 整张操作

帧列表右键菜单提供新建、复制、上移、下移、删除和撤销/重做。快捷键在列表获得焦点时生效：`Insert` 新建，`Ctrl+D` 复制，`Alt+↑/↓` 移动，`Delete` 删除，`Ctrl+Z` 撤销，`Ctrl+Shift+Z` 重做。每次操作是一次原生撤销。列表中 `F2` 修改标题、`Enter` 进入正文；幻灯片模式下 `Ctrl+Alt+N` 可直接新建。

支持多选复制／删除与连续多选拖动排序；目录拖动显示细深灰横向插入线、浮动卡片、选中行淡化及 150 ms 轻微让位，放下时才改动源码，取消不产生撤销记录。让位间距为14个逻辑像素，不画虚线占位框。应用设置或 Windows 减少动画时立即显示位置。跨文件、章节、引用依赖或拖动期间源码变化时停止移动并说明原因。新建菜单包含列表、双栏、图文、公式、定理和例子布局。

总览也预演拖动后的排列：相邻缩略图用150 ms平滑让位，目的位置用细深灰纵向插入线标明，保留淡化卡片，不画虚线框。插入线按实际缩略图图像的上下边缘对齐，并放在卡片间隙，不延伸到标题区。快速改变目标时从当前位置继续，命中判断使用稳定的原始网格，避免卡片移动后目标来回跳。取消、筛选变化、窗口调整或关闭总览会恢复正常网格；减少动画时立即显示目标位置。预演不改模型顺序或源码，放下后才执行原有整张移动和一步撤销。窗口销毁前断开模型的预演回调，目录隐藏时清除临时间隙和指示线。

筛选隐藏的页面同时退出选区，不参与后续批量操作；拖动过程中筛选改变并隐藏参与页时拒绝落下，要求重新拖动。

只修改可确认的独立源码范围，不重命名作者的标签、公式或宏。含显式标签、锚点或 frame label 的帧停止复制；被 `againframe` 引用的 frame label 停止删除。移动不能跨文件、章节命令或 `againframe` 顺序依赖。未知宏生成结构、重复 input、跨文件帧、未闭合边界、非 UTF-8 外部源等情形降级为源码导航和完整源码视图，需手工编辑。

## 预览对应关系

第一次使用旧 PDF 时需要在 TeXline 中完整编译一次。只有经现有构建认证的 PDF/SyncTeX 和同一代 Beamer 导航记录才能建立对应关系；不把 PDF 页码当作 frame 序号，也不从后续编译的工作目录读取旧预览的导航记录。

常规 `frame`、命令式 `\frame{…}`、无标题、外部 `input`、`pause`、`only`、`uncover`、`againframe` 和可核验的 `allowframebreaks` 可分组。续页的累积导航范围合并到同一逻辑 frame。数据缺失、条件化或宏生成帧、排除帧、笔记组合/多页拼版或 SyncTeX 不能核验来源时显示未映射，不猜测。

步骤按钮只改变阅读位置。源码修改后保留旧预览并显示“预览过期”；首次编译前显示“编译后显示预览”，首次失败明确说明尚无预览；已有预览时才提示保留上一版。编译中和失败有单独状态，新版预览实际载入后，左下角短暂显示“已更新”方框并淡出；切换步骤或重新打开缓存预览不重复提示。继续复用原有完整产物发布和双向 SyncTeX。光标跨 frame 时才切换当前张，不在每个按键上重渲染。缩略图由用户展开后按当前页生成，最多保留八张，缓存上限 8 MiB；关闭模式取消后台工作并释放预览。

实现参考了 [BeamerQT](https://github.com/acroper/BeamerQt) 的文档设置、章节上下文和整张管理工作流；这些功能直接作用于 `.tex`，不引入其他文档格式或运行框架。设计参考 [Dieter Rams 的设计原则](https://www.vitsoe.com/us/about/good-design)，以定位、编辑和版本状态为视觉层级。

侧栏默认只保留两行操作：新建、总览、收起各占顶行三分之一并居中；第二行提供导言、全文与搜索。搜索单击后在同一位置展开输入框和筛选，Esc 或关闭按钮结束搜索并清除筛选，恢复导言/全文，避免隐藏条件影响目录。专注模式保留原窗口大小；新开文档沿用源码左半屏、PDF 右半屏的普通并排方式，不自动最大化。

源码和 PDF 始终是两个独立顶层窗口。左右半屏是初始排列，不是锁定分栏；可以分别拖动、调整大小或移至其他显示器，专注模式不绑定两者位置。

## 可视化编辑

1.1.5 增加多图排版、公式结构与逐步显示工作台。新增对象从“插入”进入，已有对象使用“编辑此处…”，当前张的显示步骤从“编辑 → 逐步显示…”或正文右键进入。操作、取消、撤销与支持范围见 [可视化对象编辑](VISUAL-AUTHORING.md)。

- 新建下拉以六张布局示意卡展示要点、双栏、图文、公式、定理与例子；插入后光标停在新页标题内，整次插入一步撤销。
- 双击目录标题或按 F2 原位编辑，Enter 确认，Esc/离开取消；允许 LaTeX，括号错误与源码变化不会覆盖原文。
- 从新建/右键菜单插入图片，或将一个本地 PNG/JPEG/PDF 拖入源码，打开宽度、居中和替换面板。示意保持比例；PDF 文件或无法读取的位图以文件名提示，实际排版仍需编译。
- “调整图片”支持标准 `\includegraphics[width=…\linewidth]{…}`；多图时先将光标放入目标命令。保留已有对齐结构，自定义选项交给源码编辑。资源复制到 figures，取消不写入，源码冲突停止应用，应用与撤销均为一步；撤销保留资源文件。
- 搜索旁筛选菜单可切换“按章节浏览”，折叠/展开既有章节、点击子页定位；这一视图不移动章节源码，整张排序继续使用普通目录或总览。
- 总览显示选中数量，沿用已有拖动插入提示和多选操作。
- 新建菜单“我的布局”可保存当前页的正文结构并命名、插入、删除，最多30个。为保留宏与资源依赖，本轮仅在原讲稿内复用；含标签或依赖导致无法安全复制的页不保存。未实现跨讲稿资源迁移或整节移动。

## 写作与公式预览的一致性

标题编辑的 Enter/Esc 优先作用于编辑框；章节目录沿用原位编辑。确认未改动的标题或图片设置不新增撤销步骤，也不重写原有图片宽度。普通目录的多行标题按实际条目宽度计算行高。

源码和内嵌幻灯片预览共用公式悬停解析：保持原有延迟，幻灯片模式的浮层优先位于目标上方并限制在所在面板内。切页、缩放、编辑和退出模式时关闭浮层。Beamer 标签采用实际幻灯片锚点，并处理整页收集造成的 SyncTeX 行号偏移；逐步显示按当前可见公式定位。源码与 PDF 不匹配时不展示旧的编译公式。

公式浮层按内容自然宽度显示，安全收紧公式与右侧编号的空白；长内容按空间等比例缩放。SVG 转换使用私有目录内相对输出路径，兼容 Windows 中文路径。保留编号、矢量路径与当前引用行间距；复杂图形公式不重排，转换工具不可用时仍保留原有位图降级。

无编号公式遇到 Beamer 末行同步节点时，仅在整页源码公式行数与实际排版行盒一一对应时恢复定位。多行和矩阵保留完整高度，超高内容缩放而不截断；浮层优先使用 PDF 页外空白，并避开当前完整公式区域。复杂布局无法可靠匹配时保守不显示，不用整页替代公式。
