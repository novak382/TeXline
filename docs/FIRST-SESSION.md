# A 15-minute writing session / 约 15 分钟的写作试用

This is a task sheet for actual researchers, not a record of completed user
research. No external participants have tested this candidate yet.

1. **Install and start (2 minutes).** Follow INSTALL. Copy `examples/first-session`
   into your own writing directory. Record Windows version, display scale,
   TeX distribution and the application version. Open `paper/main.tex` and compile.
2. **Write a paragraph (4 minutes).** Add two sentences explaining when equality
   holds in the rank-one norm bound. Compile and verify your sentences in the
   PDF. Navigate between source and PDF using the editor's SyncTeX actions.
3. **Read while writing (3 minutes).** Open the article structure, navigate to
   the proof in the included file and try Full file / Section. Pin the theorem
   or proof for reference. Edit an explanation, undo it once, then redo it.
   Confirm the complete paper still saves and compiles.
4. **Organize a talk (4 minutes).** Open `talk/main.tex`, compile, and use its
   slide directory. Move a slide, inspect the source, undo and redo. Change a
   title and add a note. Export projection/speaker PDFs if your distribution
   provides the required Beamer packages; compare the note visibility.
5. **Report (2 minutes).** Fill FEEDBACK. State where you hesitated, whether you
   could complete the writing task, and whether you would use it on your own
   manuscript. Report failures as well as successes.

If a compile fails, record the first real error and the engine name. Distinguish
a missing TeX package from an editor failure. Do not spend the whole session
repairing your TeX installation. Do not share private papers or the complete
settings folder.

中文：先安装并编译示例论文，实际写入两句话并在 PDF 中确认；尝试目录、本节和固定
查阅、撤销／重做；再编译讲稿、移动一页、改标题与备注并尝试两版导出。最后填写反馈。
遇到缺宏包时记录首个错误即可，不把安装 TeX 的时间混入编辑器写作体验。
