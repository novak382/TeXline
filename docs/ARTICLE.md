# 自动文章结构与定理查阅

普通文稿仍从连续源码开始。未保存的新稿保持纯写作界面，首次保存后自动识别，避免目录使用尚不存在的文件路径。带有文档类声明、且有至少两个写作单元（有 chapter 时按 chapter，否则按 section，再按 part 识别）的非 Beamer 文档会自动提供文章结构；只有一个 section 的 draft/note（包括它的 subsections）继续使用简单编辑界面，不出现文章管理控件。无需选择论文或 note 模式。文稿写长、缩短或撤销时自动重新识别；短 note 不创建文章专用文件观察器。

## 写作空间与导航

“全文／本节”合并在原工具栏中，不新增顶部行。单文件文稿的“全文”显示完整源码；多文件文稿显示“本文件”，明确当前可编辑的物理文件。章节名称位于状态栏，状态消息出现时优先显示消息。

左上结构图标或 Ctrl+Shift+O 可展开／收起目录，点击目录内关闭按钮也可收起；展开偏好按论文主文件保存。目录始终靠左显示，不替换正文；默认宽度最多240个逻辑像素，手动拉宽也限于窗口宽度的三分之一，保留至少半窗的可写区域。半屏和更窄的窗口也保持源码可见；较窄时选定章节后收起目录，也可按 Esc 收起。窗口缩小时目录随宽度收窄。专注模式暂时收起目录与范围控件，并展开连续源码；退出后恢复之前的范围选择与目录显隐。

目录包含导言、可识别的摘要、章节和小节。“筛选”文字按钮临时展开目录筛选框，区别于顶栏的正文查找，可按 Esc 关闭并清空。筛选包括章节和对象标签，无需先打开对象列表；无结果时明确提示。清空筛选恢复先前折叠状态，正文前方插入文字不丢失折叠状态。长标题单行省略，提示保留完整文字。“定理与证明”按需显示定理、引理、证明、定义及自定义 theorem 环境，以环境名和可识别的标题或标签区分。

## 本节编辑与原文件

本节是原 QTextDocument 的可见范围，不是另建的文稿。切换视图保留完整缓冲区、撤销栈和磁盘原稿。保存、编译、恢复仍使用完整源文件；本节内 Ctrl+A、Ctrl+Home／End 和边界删除受当前范围约束。进入新的本节时，查找默认跟随本节范围；本节中主动选择“当前文件”等范围后仍尊重该选择。切换注释后的撤销返回原编辑位置，避免误跳到文首并退出本节。外部定位到隐藏位置会自动展开全文。

新标题、跨文件范围或无法确定的条件结构使原范围失效时，会展开完整源码。仅在源文件中具有明确整行边界的章节才允许“本节”。跨文件的章节仍可定位；控件会说明需要按源文件编辑。

本节内输入只重新检查编辑附近段落的可见性；切换范围时仍检查完整边界。光标移动复用当次已解析的文件路径，避免按章节数量重复访问文件系统。

## 多文件论文

按字面 input／include／subfile 的出现顺序组织同一篇论文的结构。选择子文件中的章节会复用或打开其源码窗口，并继承论文目录及会话中的主文件。无标题子文件中的定理仍归入实际逻辑章节。未保存的子文件修改实时进入目录，忽略修改并关闭后恢复磁盘内容；缺失子文件重建后自动刷新。各源文件继续独立保存与撤销；已有显式 root 声明优先，不向原稿写入额外声明。

扫描在后台进行，可取消，数量与容量有上限；评论、字面量及宏体中的假标题不会作为编辑边界。条件命令、重复包含、动态文件名、includeonly、跨文件章节及不明确的行边界采用保守降级。它不是完整 TeX 展开器。

## 定理与证明查阅

已保存文稿的源码右键或“阅读”菜单中的“固定查阅”在下方打开可关闭的只读区域；也可以在目录的节内对象上右键固定。光标所在的未标号证明也可直接固定。

只有与当前稿件匹配的已编译内容才显示 PDF 片段；定理裁剪不混入相邻证明。不能安全裁剪、尚未编译、跨页或未标号的对象显示当前源码。编辑会立即移除旧渲染并更新；未标号证明的查阅范围跟随前方的源码插入，避免继续使用过时的字符偏移。切换对象、编辑或删除目标后立即撤除旧内容并禁用“定位源码”；仅在当前目标解析成功后恢复定位。缺失或重复对象明确说明。编译完成自动重新校验现有查阅，失败保留上次 PDF 但不认证过期片段；成功修复后自动恢复当前片段。矢量片段随窗口变窄等比例适配。

首版只提供结构导航和本节视图，不重排章节、不改写 LaTeX、不自动拆分文件。

源码查阅使用与正文一致的等宽字体和阅读字号，跟随编辑器缩放；加载期间复用同一个等待区域，连续输入不反复建立控件。过期片段仍立即撤除，等待状态不能定位旧目标。
