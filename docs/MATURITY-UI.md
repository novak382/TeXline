# 界面成熟度与语言

TeXline 保留浅色控件、单层菜单入口与现有写作布局。设置分类沿用通用字号；搜索结果按实际控件去重，Enter 定位设置，Esc 先清空搜索，再关闭窗口。未增加常驻按钮。

## 语言

在「菜单 → 语言 / Language」或「设置 → 常规 → 语言」选择简体中文、繁體中文或 English。繁体中文使用台湾常用界面用语，例如「設定、儲存、檔案、原始碼、游標」。中文系统的台湾、香港、澳门及 Hant 标记会映射到繁体中文。语言菜单始终保留各语言自身的名称。

引导开头页也提供这三个语言选项，同排等宽显示，选择后立即保存。六页内容和演示媒体保持原有版本。

命令和设置搜索同时识别简繁写法及常用术语对应，例如「保存／儲存」「源码／原始碼」。翻译只处理应用内建文案；正文、文件名、文献条目、用户片段与格式化参数不做字形转换。

`ResearchAppearance` 提供统一显示与搜索入口，`ResearchSettings::words` 和既有界面复用它。繁体词表保存在 `res/research/ui-zh_TW.json`，Qt 与 PDF 控件分别使用对应 TS 目录。新增内建文案应同时维护三个语言版本、占位符与搜索词；不要对完成插值的用户内容做全文转换。引导内容和录制仍保持原有版本。

## 响应与编译

重复显示窗口时，翻译使用反向索引和有界缓存；不再为每个相同标签反复扫描完整词表。动画沿用现有节奏与缓动，若捕获窗口已超过两个显示帧的时间预算，直接显示可操作的内容。输入和手动滚动仍立即解除动画覆盖。

专注切换只捕获界面边缘，正文与 PDF 阅读区域不参与淡入淡出；侧栏与弹窗过渡层独立绘制背景，避免连带重绘正文。反向操作从当前画面继续，连续请求不排队。大型源码的后台排版使用有界批次，让出事件处理时间；光标定位和当前可见范围仍立即排版。不要通过延长动画掩盖同步布局停顿。

专注模式折叠/恢复侧栏时也会改变正文宽度，应与直接开合侧栏共用同一排版缓存事务。回归必须同时测量侧栏已打开和已关闭的专注进出，不能只测空侧栏。

编译提交时合并两份依赖记录共有的校验工作。所有提交边界仍检查实际内容及修改时间；前后记录不一致时拒绝提交。不减少 TeX 排版次数，不使用跨提交边界的文件哈希缓存。

原生隐藏桌面验证与真实输入法、物理鼠标、显示器合成、混合缩放双屏及用户试用分开记录。具体覆盖和测量结果见对应轮次报告。
