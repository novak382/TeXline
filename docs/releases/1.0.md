## A new place for your next idea

**TeXline 1.0** brings focused writing, connected reading and visual LaTeX tools to a light Windows workspace. Write a note, work through a proof, or prepare a Beamer talk while keeping ordinary source files at the center.

### Write at the scale of your thought

Move between the full document and a single section. Enter focus mode without losing your scope or position. Adjust font and spacing with a live preview; choose optional typewriter scrolling and additional menu entries in settings.

### Read without losing the thread

Pin a theorem, proof or equation beside your draft. Follow explicit references and return through your reading trail. Link a local bibliography, find a citation, and revise existing citations in place.

### Leave room for a better version

Keep a named version of a selected passage before rewriting. Compare it with your current text and recover what you need, with undo. Save a writing place to return later to the section, selection, pinned reading and PDF position.

### Work visually where it helps

Arrange multiple figures and captions, edit table cells, shape formula structures, and control progressive reveals in Beamer. Inspect the preview and apply the change; recognized objects can be reopened for editing.

![A real multi-image typeset preview in TeXline.](https://github.com/novak382/TeXline/raw/main/docs/media/figures.png)

### Give your talk the whole preview

Navigate and reorder Beamer slides, work on the current frame, then expand the preview while keeping the slide list nearby.

### Start here

1. Install [TeX Live](https://tug.org/texlive/) or [MiKTeX](https://miktex.org/).
2. Run the Setup download, or extract the portable ZIP to a writable folder. Open `TeXline.exe` there.
3. Open a file or create one from the start page, then choose **Compile**.

The installer works per user, creates no shortcuts and leaves file associations unchanged. The package is unsigned. See [known limitations](https://github.com/novak382/TeXline/blob/main/docs/KNOWN-LIMITATIONS.md) for compatibility and validation boundaries, and [report issues](https://github.com/novak382/TeXline/issues) with a small shareable example.
