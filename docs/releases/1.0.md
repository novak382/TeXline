# TeXline 1.0

LaTeX, with room to think. A free, local Windows editor for notes, papers and Beamer talks, built on TeXworks.

**[Download for Windows](https://github.com/novak382/TeXline/releases/download/v1.0.0/TeXline-1.0.0-Setup-x64.exe)** · [Portable ZIP](https://github.com/novak382/TeXline/releases/download/v1.0.0/TeXline-1.0.0-Portable-x64.zip) · [Website & demos](https://texline.dev/)

Windows 10/11 x64 · English · 简体中文 · 繁體中文

![An archaeology note and its compiled page in TeXline.](https://github.com/novak382/TeXline/raw/main/docs/media/showcase/archaeology.png)

## In this release

- Write in the full document or focus on one section. Adjust the font and line spacing to suit your reading.
- Keep a theorem or equation beside your draft, follow explicit references and return to your place. Move between source and PDF with SyncTeX.
- Edit figures, tables and formula structures visually. Reopen supported content to revise it, with undo.
- Reorder Beamer frames, set progressive reveals and expand the preview while keeping the slide list visible.
- Save a passage before rewriting, or save a writing session to return to your section, selection and reading position.
- Search local bibliographies, reuse templates, navigate multi-file projects and work with Git.

[See the workflows](https://github.com/novak382/TeXline#readme) · [Try the four demo projects](https://texline.dev/samples/showcase-samples.zip) · [简体中文](https://github.com/novak382/TeXline/blob/main/README.zh-CN.md)

## Get started

1. Install [TeX Live](https://tug.org/texlive/) or [MiKTeX](https://miktex.org/) separately.
2. Run the installer, or extract the portable ZIP into a writable folder. Open `TeXline.exe`.
3. Open a file or start from a template, then choose **Compile**.

Editing and local compilation need no account. The installer works per user, creates no shortcuts and leaves file associations unchanged. The package is currently unsigned. Git features require Git.
