# 交互动效

TeXline 的动效表达展开、加入、移除和位置变化。保持浅色极简界面，不增加常驻控件。正文输入、选区、查找、阅读定位和编译控制优先于动效。

## 时长与范围

| 操作 | 反馈 | 时长 |
| --- | --- | --- |
| 文章结构栏、幻灯片目录和预览、固定查阅面板 | 按停靠方向揭开或收回；反向从当前可见位置继续 | 160 ms |
| 章节树展开与折叠 | 使用 Qt 的树分支展开，行内容保持原有字号 | 150 ms |
| 新建或复制幻灯片 | 新卡片从左侧 10 px、下方 8 px 进入；已有项目让位 | 160 ms |
| 删除、撤销和重做幻灯片 | 删除项短距离淡出；保留项目向最终位置移动 | 160 ms |
| 幻灯片拖动 | 相邻项目移动；侧栏 14 px 的插入间隔与深灰实线；总览实线贴齐实际缩略图 | 150 ms |
| 新查阅内容、备注、产品弹窗 | 轻微淡入，最多移动 6 px；直接操作立即释放临时画面 | 160 ms |
| 专注模式切换 | 顶栏等界面元素淡化；正文和 PDF 阅读区域不叠加旧文字 | 150 ms |
| 短暂状态提示 | 淡入；到期淡出；悬停保留，持久进度和未解决警告不淡出 | 120 / 160 ms |
| 引用悬浮提示、首次引导 | 保留现有轻量过渡，并遵守减弱动画设置 | 120 / 140 ms |

菜单、原生文件窗口沿用系统行为。光标与选区、输入法提交、全文/本节、查找结果、滚动、PDF 翻页和缩放、编译开始/停止、错误信息及过期引用清除保持即时响应。没有可编辑的 PDF 页面插入功能，因此不为 PDF 阅读制造卡片入场效果。

## 布局与输入

- 面板先提交最终布局，正文只按最终宽度排版一次。临时画面只表现位置和揭开过程，不连续改变文字宽度。文章结构仍限定在窗口三分之一以内，写作区至少占半屏；后台解析保留用户正在使用的栏宽。
- 保留编辑器光标、选区、水平滚动及首个可见文本锚点。文首始终保持第一行可见。不会因动画修改源码、生成撤销记录或延迟输入事件。
- 同一面板途中反向从当前进度继续；其他面板切换、窗口尺寸变化和直接写作及时结束旧过渡。临时画面不截获鼠标或键盘。
- 字体缩放、光标跳转或阅读滚动会立即释放旧的正文画面。生成面板截图前恢复子控件绘制，不能用仅包含背景的图片替代正文。面板展开和新内容到达只使用一层过渡，避免先变深再变浅。
- 卡片身份来自文件与实际帧源码；同内容的多个副本分别匹配。只有插入、删除、重排及其撤销/重做触发让位，普通标题和正文修改不使整列跳动。移动中的原生模型已经提交，直接操作和滚动会立即结束展示过渡。
- 总览的上一版提示放在已有底栏，出现时不改变画布高度。同一份 PDF 的未变缩略图在撤销与重排中保留；实际新编译版本重新读取。内部滚动条改变可用宽度时，从当前卡片位置重新计算目标，仍按原定时限结束。
- 编译或源码变化后，查阅内容先按原有规则立即失效，再显示当前数据；不保留旧定理做淡出。面板画面随当前数据刷新，避免动画期间显示过期引用。
- 只覆盖变化区域；固定查阅展开时不能把旁边的结构栏刷白。卡片过渡沿用所在列表实际底色。关闭、隐藏、改变尺寸和超时后释放临时图片。
- 透明列表先按实际窗口底色合成实底卡片，再移动和遮挡；最终模型的标题不会从卡片下面透出来。中间帧检查同时核对正文文字是否持续可见，以及侧栏文字是否因两层绘制而重影。

## 减弱动画与开销

统一读取 Windows 客户区动画开关及已有的私有 `researchReduceMotion` 设置，不修改系统偏好。减弱动画时直接显示最终状态，不生成过渡截图。树分支在实际操作前重新读取策略。

新增过渡只在运行的 160 ms 内启用计时器；每帧移动或裁剪既有画面，不重新解析论文或渲染 PDF。初次打开文稿、自动识别模式和后台重新解析不播放面板入场。普通编辑过程中没有新增轮询。

## 验证方法

`unit-tests/research-native/system-motion-test.cpp` 在未激活的私有 Windows 桌面测试实际 Qt 控件，读取真实中间帧，覆盖面板开合、反向、连续操作、输入和组合文本提交、卡片增删重排与撤销、总览、减弱动画、关闭和窗口变化。源文件、报告和录像分目录，避免测试资料触发项目文件监听。

与文章、幻灯片拖动、专注、查阅、查找、编辑和引导回归一起验证中英文、有效 100/125/150/200% 缩放，以及实际屏幕工作区的一半宽度。运行录像使用 `QWidget::grab` 的实际绘制帧和实测时间戳编码，不用设计图代替产品过程；录制时缓存帧，在片段结束后压缩，减少录制对动画的影响。同一片段使用固定比例与不透明画布，改变窗口尺寸时也不遗留旧边框。GIF 根据绝对时间边界量化为 10 ms，避免把每个约 33 ms 间隔都取整到 30 ms 而累计加速。演示片段保留实测速度，完整压力操作另存。物理鼠标、真实输入法候选窗、前台 DWM 和双屏仍属于单独验收范围。
