# 查阅与写作现场

这些入口复用现有省略号菜单和命令面板，不增加常驻工具栏。

- **查阅**：正文右键“查阅此处上下文…”，或主菜单直接选择“查阅此处上下文…”；`Alt+F12` 查阅光标所在位置。右键查阅不移动写作光标或清除选区。固定查阅栏的“上下文”打开同一窗口。正文中的链接继续查阅，文件名返回准确的源码位置；前进/返回保留选区及阅读位置。“此处引用”与“引用此处”只表示显式引用关系，相邻证明单独标明。
- **写作现场**：“文件 → 保存写作现场…”（位于保存附近），确认自动生成的名称或自行修改，然后保存。命令面板搜索“接着写”可直接进入“恢复写作现场…”；右键不放置这一全局操作。选中记录可先看正文摘录，再恢复章节范围、光标与选区、固定查阅、PDF 位置和必要布局。列表右键可重命名或删除记录。原文件移动或定位不唯一时会说明原因，不猜测恢复位置。
- **局部版本**：选中段落、证明或章节，右键“保留选区版本…”即可保留，名称预填且可修改；无选区时“编辑 → 查看局部版本…”查看已有记录。内容变化页可取回一处，源码对照保留精确文本；“恢复整段”一次恢复整个范围。两种恢复都支持一步撤销/重做，并保留恢复前的本地历史。记录右键可进入已有本地历史或项目版本与协作。
- **打字机模式**：在“设置 → 编辑”开启，默认关闭。输入时当前可视行保持在窗口约 42% 的高度；手动滚动、鼠标选字和查阅不触发居中。

查阅及写作窗口沿用同一 15 px 界面字号，以字重、间距和轻微色差区分层级。源码对照跟随编辑器字体。摘录不会运行 LaTeX；数学和未知宏保留源码，只有明确的环境外壳及标签从阅读摘要中省略。精确源码始终可打开。

幻灯片模式中，顶部已有的结构按钮和 `Ctrl+Shift+O` 直接展开／收起左侧幻灯片列表；“查看 → 幻灯片列表”也可切换。列表菜单中的“筛选幻灯片”只筛选标题、章节和页码。顶部 `Ctrl+F` 查找源码，范围选择始终可见，可选当前张、文件、选区或已打开源码；关闭或 Esc 返回编辑器。

## 保存与导入

源码查找栏始终为一行，只占编辑区；范围始终可见，替换与低频选项进入行尾菜单，Ctrl+H 直接打开替换面板，Enter/Shift+Enter 前后查找。窄窗口将前后按钮和计数收进菜单，Esc 先关闭弹出面板，再关闭查找并返回编辑。预览的 SVG 展开图标可暂时隐藏源码，保留列表和大预览；再次点击或 Esc 返回。展开中调用查找会先恢复编辑区。

文稿保存复用受保护的原子替换，短暂读占用会有限重试；失败时保留当前修改与恢复草稿。文献导入可显式勾选“更新已有条目，保留项目引用键”，预览后确认；现有项目字段不会因导入中缺少该字段而消失。DOI 与 arXiv 标识用于重复识别。项目 ZIP 复用已有模板读取及安全检查，选择主文件后导入，保留项目资源和隐藏配置。

## 验证边界

原生回归使用独立样稿、私有设置和未激活的桌面。合成输入法事件不等同于真实输入法或真人试用；真实 Zotero 私有库、物理鼠标、前台合成和混合缩放双屏需另行验收。局部版本是本地命名记录，不会自动创建 Git 提交。

## 首次操作与按需示范

命令面板复用本地词表，支持“改之前备份”“接着写”“这个定理在哪里用到”等写作意图；当前可用操作优先，主要写作能力附一行用途。未命中的语句不会假装理解。

没有文献条目时，引用窗口直接显示“关联文献文件…”，关联成功后在原窗口继续选取。保存现场与版本窗口预填可修改的名称，展示将保存的摘录，成功后显示记录名称。

六页使用示范围绕打开论文并看到 PDF、插入引用、定理引用与返回、保留与取回证明、保存与恢复现场、讲稿排序及展开预览。查阅、版本与现场窗口及文献添加菜单可直接回看对应短示范；关闭后返回当前操作，不改变首次引导的已读状态。已看过引导的用户不会因内容更新被重新打扰。

“陌生用户能独立完成”需要真实试用：记录首次点击、犹豫位置、求助次数、首次是否完成以及第二次是否找回入口。原生自动流程只验证软件行为，不替代这项验收。
