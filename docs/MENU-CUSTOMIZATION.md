# 菜单与快捷键

设置 → 菜单与快捷键 → 菜单，按正文右键、编辑菜单、插入菜单、幻灯片菜单选择额外入口。
默认保留基础操作和当前位置相关操作；未勾选的入口仍可通过原有快捷键及“查找操作”使用。
保存后下次展开菜单即生效，无须重启；取消不写入，重置本页在保存后恢复默认。

正文右键保留基础编辑、定位 PDF、查阅、选区版本，以及识别到的引用、公式、图片和幻灯片逐步显示。
固定到下方、存为片段、设为引文和插入子菜单为可选入口。
编辑菜单保留基础编辑、缩进、注释和局部版本；整行编辑及补全快捷入口可选。
插入菜单保留图、多图、表、公式、文献和脚注；片段、自定义命令、引文可选。
“设为引文”统一归属于插入菜单，与命令注册一致。
幻灯片右键按剪贴板、编排、撤销重做分组，图片、备注、步骤导航及退出快捷入口可选。
目录菜单保留筛选、导出、完整源码及导言与模板；重复的导言快捷入口及缩略图可选。

`ResearchMenuChoices` 统一定义入口身份、默认值和设置文案，复用设置控件的保存、取消、重置与搜索。
过滤仅移除菜单借用的 QAction，不改变原命令的可见、可用状态及快捷键所属控件。
长期菜单维护有序的弱引用，接纳晚注册的动作并安全处理销毁；临时右键菜单按同一配置过滤。
普通与专注模式共享现有菜单对象。菜单选项与快捷键共用一个分类，分别切换“菜单”和“快捷键”；快捷键本身不受菜单显隐影响。

验证入口：unit-tests/research-native/menu-choice-test.cpp。真实鼠标、输入法及陌生用户的易发现性需另行试用。
