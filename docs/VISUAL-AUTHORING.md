# 可视化对象编辑

三类编辑器共用轻色工作台：左侧是当前对象或真实排版预览，右侧是该对象的调整项。更改先留在草稿中，点击“应用”才改写源码；取消或 Esc 放弃草稿。预览自动更新，手动更新放在原有调整菜单中。没有新增常驻工具栏，也没有更新引导。

## 多图排版

从“插入 → 多图排版…”进入。添加或拖入多张本地图片，直接在画布中选择、拖动排列；右侧调整列数、统一宽度或限制高度，并填写总标题和选中子图标题。“调整图片”提供裁剪、前移、后移和移除。切到“排版效果”查看使用项目导言实际编译的结果。

光标位于已有标准多图 `figure` 内时，“编辑此处…”重新打开该组。支持标准 `subfigure` 和简单的多个 `includegraphics`；保留浮动参数、标题、标签及可识别的裁剪。复杂自定义布局保持源码，不能可靠识别时不覆盖。每组最多 24 张；单个新资源最大 64 MB。

资源在确认后才导入项目。取消不复制；任一资源或原稿已变化时保留草稿并停止应用。应用为一步撤销，撤销后保留资源文件供重做使用。预览中的编号和浮动位置以全文编译为准。

## 公式结构

从“插入 → 公式结构…”进入，也可在已有矩阵、分段函数或多行公式处使用“编辑此处…”。“编辑”显示与数学结构对应的单元格和括号；“排版效果”显示实际编译结果。

右侧选择矩阵括号、行列式、分段函数、对齐或逐行编号。“调整行与列”增删行列；单元格支持区域复制、粘贴、清空和草稿撤销。单元格中的内容仍可使用项目已有的 LaTeX 宏。

已有结构的普通单元格修改只替换该单元格，外围公式、标签与无关空白保留。新增独立结构自动包裹数学区域；在已有数学区域内不重复包裹。一次应用与必要的本文件宏包补充共同撤销。子文件复用主文件已加载的宏包；若主文件缺少宏包，先提示加载，不暗中改写另一个文件。

支持 `pmatrix`、`bmatrix`、`Bmatrix`、`vmatrix`、`Vmatrix`、`matrix`、`cases`、`aligned`、`align`、`align*`，最多 80 行、24 列。自定义行距、含注释结构的增删及无法可靠识别的布局留在源码中编辑。

## 幻灯片逐步显示

将光标放入一张幻灯片，从“编辑 → 逐步显示…”或正文右键进入，也可搜索命令。左侧以完整讲稿页为主，右侧选择内容并设置出现和结束步骤；“持续”表示显示到后续步骤。下方用 SVG 箭头或页码查看已编译的各步。

“安排步骤”支持按列表顺序逐条显示、全部从第一步显示，以及为当前源码选区设置步骤。支持常用的绝对步骤和简单 `pause` 列表；相对步骤、模式限定和自定义规则继续在源码中编辑。只修改对应显示规则，保留内容和其余源码。

预览使用项目实际导言与引擎，取消只终止私有预览任务。最多 40 步，已编译页面有总计 64 MiB 的内存上限；切步复用缓存。应用为一步撤销，Esc 返回源码。
