# 首次使用引导

引导由 `src/ResearchOnboarding.cpp` / `.h` 独立实现，文字、布局、样式和演示放在外置内容包中。面向已熟悉 LaTeX 的研究者，先选择简体中文或 English，再用六页了解按节论文写作、固定查阅、专注写作、Beamer 逐页组织与输出、公式及双向定位、外部修改审核。各页只用标题和一句话，不加末尾句号，主操作沿用浅色按钮。

引导可以跳过、暂停、返回和直接点击进度点。完成、跳过、关闭或按 Escape 会记住观看状态。普通内容调整不会再次打断已看过的用户。默认／专注及源码／PDF 窗口均可从“更多 → 帮助 → 认识 TeXline”重新打开，传统帮助菜单也保留入口。选择语言会保存为应用界面语言；第一页的“返回”可重新选择。

## 外置内容包

源码位于 `res/research/onboarding/`，安装到程序旁的 `resources/onboarding/`：

- `content.json`：中英文文字、页面顺序、素材路径及布局参数
- `style.qss`：引导自身的字体、颜色、按钮与留白
- `media/*.gif`：当前真实界面的演示，中英文各六段
- `media/recordings.json`：录制程序与夹具身份、动作、实测时长及素材哈希
- `sources.md` / `sources.json`：公开材料的来源、许可、改编说明及原始文件哈希

重新打开引导时读取内容包。修改文字、页数（1–12 页）、顺序、布局、样式或 GIF，无需重新编译 EXE。增加新的交互能力时才需修改独立模块。

文字按纯文本显示。媒体路径必须在内容包内；单文件不超过32 MiB，尺寸不超过1920×1200。JSON 缺失、损坏或格式不兼容时回退到内置文字和默认样式；演示缺失时仍能继续或跳过。运行时保留静态图片支持，当前发布包全部使用 GIF。

`schemaVersion` 表示格式版本（当前为1），`revision` 标记内容批次；`researchOnboardingSeen` 单独保存观看状态。

## 单独分发

在项目根目录执行：

```powershell
python tools/package-onboarding.py --check
python tools/package-onboarding.py --destination out/onboarding-package/resources/onboarding
```

关闭引导后，将生成的内容目录分发到用户程序旁的 `resources/onboarding/`。打包器逐项校验素材和复制哈希，先完成临时目录，再切换到目标目录并保留旧目录备份；重开引导即可加载替换后的资源。此流程无需编译主程序，也无需常驻监听或联网下载。

`layout` 可调整 `width`、`margin`、`spacing`、`mediaHeight`、`fadeDuration`，单位为逻辑像素／毫秒，模块约束其范围。小屏及高缩放优先保留完整导航，缩小演示区域。样式仅作用于引导窗口。

## 实录案例

主题保持按功能组织；材料选取实质研究任务，不按学科分类分页。数学、物理和工程论述为自行撰写的完整推导；真实馆藏图片、公开观测和文献的来源及权利逐项列在 `sources.md` / `sources.json`，不使用个人论文，不编造作者或测量结果

1. 从短 note 切到完整谱稳定性论证，选择本节、收起目录、写入结论，实际编译并在 PDF 中看到新文字
2. 在多文件变分证明中搜索、固定已编译定理与当前源码证明，继续写作、定位源码并收起查阅
3. 在普通 article 的共同资源研究论述中收起界面，继续写正文，逐字校验撤销恢复
4. 在最短路径报告的当前张编辑归纳论证，把第4张 Path invariant 拖到第3张 Convergence 上方，检查实际让位动画、源码顺序和重新编译后的预览；查看讲者备注，选择投影版与讲者版输出。演示在展示选择后取消，不将选项展示表述为已生成输出
5. 修改阻尼振子推导并保存，保留带版本标记的上一版 PDF；悬停看公式，Ctrl 双向定位同一公式
6. 外部编辑器保存无冲突修改及冲突；安全部分先自动合并，查看两个真实版本后全部采用，并检查没有额外覆盖磁盘

通用图表／文献插入的差异性较弱，完整导出是 Beamer 工作流的一部分，因此不再各占一页。录制没有调用 AI 服务。

`unit-tests/research-native/onboarding-recording.cpp` 使用候选程序同一组应用对象及修正后的依赖。仅在未激活隐藏桌面、独立研究稿件和私有设置中运行。捕获实际 Qt Windows 窗口、菜单、下拉列表、对话框和公式浮层。指针及修饰键标签是脚本操作目标提示，原始窗口内容不替换、不重绘；不移动物理鼠标。拖动片段脚本驱动产品自身的 `SlideList::animateGap` 和受保护的 `dropBefore` 回调，录下真实卡片位置与源码变更；不驱动系统 OLE 拖放，不能作为物理鼠标拖放验收。

录制检查实际文稿、目录顺序、编译结果、备注文本、PDF 纸张比例及双向定位结果。只有通过检查的整轮录制才可编码：

```powershell
python tools/encode-onboarding-recordings.py --recordings <recording-folder> --destination res/research/onboarding/media
```

录制先缓存实际绘制帧，片段结束后才压缩 PNG；短过渡采用较密采样，普通阶段降低采样。编码按绝对时间边界量化到 GIF 的 10 ms，不逐间隔取整，避免累计改变播放速度；仅保留明确的末尾停留，不加速编译和导出。播放器只解码当前片段，离页或关闭即释放；隐藏或最小化暂停，支持用户暂停／恢复，并尊重 Windows 减少动画设置。

原始帧、时间戳、输入动作、编译身份、回归结果和失败证据保存在项目 `.local/`，不发布到内容包。隐藏桌面的脚本验证不代表已经覆盖物理鼠标、输入法、前台合成动画或双屏。
