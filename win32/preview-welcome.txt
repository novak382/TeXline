TeXline — research writing with ordinary LaTeX files

TeXline v1.0.0 installs the Windows x64 editor, PDF support data, local introduction,
examples and license notices. Install TeX Live or MiKTeX separately to compile.

The installation is for your Windows account. Choose a writable folder. No
shortcuts or default file associations are created. Start TeXline.exe from the
installation folder and follow docs/FIRST-SESSION.md with the included examples.

Close your own TeXline session before upgrading. Your settings and recovery data
are kept beside the application; uninstall preserves user-created files.

This is an unsigned offline build. Physical IME, mouse drag/drop and
multi-monitor acceptance remain open. No external researcher trial has completed.
