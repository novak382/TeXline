# First-session examples

Original minimal examples written for this project. They contain no private
manuscript text or external research claims. The mathematical statement follows
directly from the norm triangle inequality. The example TeX text is dedicated
to CC0; the rest of TeXline retains its applicable software licenses.

Copy this folder into your own writing directory before editing. Compile each
`main.tex` with pdfLaTeX. The paper requires amsmath/amssymb/amsthm; the talk also
requires Beamer. These packages are supplied by your separate TeX distribution.
