# The release-page sample

Copy this folder to a writable location, open `note.tex` or `talk.tex`, and compile with pdfLaTeX.
The note demonstrates a rank-one operator-norm calculation. The talk presents the same idea in three frames, including a proof with progressive reveals. These are independent illustrative documents, not a user manuscript.
